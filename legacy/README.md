the repo.

It is preserved for reference and logic-mining only.

Current reset work should not treat these files as the active target
architecture unless something is intentionally restored from here.

  - stage-based redesign packages and CLI
- `sql/`
  - redesign bootstrap SQL from the staged implementation
- `tests/`
  - tests coupled to the staged implementation
- `docs/frontend/`
  - prior frontend reset, readiness, and prototype docs
- `configs/data/`
  - prior override/editorial/headshot config bundles
- `frontend-v1/`
  - the previous Astro lineage prototype source
